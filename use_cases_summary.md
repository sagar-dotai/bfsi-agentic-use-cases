Use Cases Overview (Condensed)
1) IT Strategic Decision Support
   - Target: CIO/CTO/Tech Strategy
   - Goal: Evidence-backed recommendations for tech investments, vendor selection, multi-year roadmaps.
   - Artifacts: tech_roadmap_2024-2026.md, vendor_eval_2026.csv

2) Cybersecurity Policy Advisor
   - Target: CISO/Security Engineering
   - Goal: Draft/update policies, map controls to frameworks, produce audit checklists.
   - Artifacts: privileged_access_policy_v1.md, audit_findings_2026Q1.csv

3) Incident Triage & Remediation Agent
   - Target: CISO/Security Engineering/SRE
   - Goal: Triage SIEM alerts, enrich with threat intel, run scans, open tickets, produce exec brief.
   - Artifacts: sim_siem_alert_20260902.json, ticket_template.md

4) Cloud Cost Optimization Agent
   - Target: CTO/Engineering/FinOps
   - Goal: Analyze billing and IaC to propose rightsizing and schedule shutdowns; optionally create IaC PRs.
   - Artifacts: billing_sample_aug2026.csv, terraform_payments_example.tf

5) Regulatory Change Management Orchestration
   - Target: CTO/CISO/Tech Strategy
   - Goal: Detect regulator updates, analyze impact, create remediation backlog, coordinate cross-team execution.
   - Artifacts: regulatory_notice_RG-2026-07.txt, service_control_mapping.csv

6) Digital Transformation Program Manager (multi-agent)
   - Target: CIO/CTO/Engineering Heads
   - Goal: Orchestrate multi-year transformation: discovery, architecture, delivery orchestration, risk tracking.
   - Artifacts: kpi_trends_q1-q3_2026.csv, legacy_app_inventory.csv

All artifacts are synthetic and intended for prototyping in Copilot Studio.
